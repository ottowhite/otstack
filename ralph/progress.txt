## Codebase Patterns
- MockRepository has `_default_branch` field (default "main") for testing default branch behavior
- Test helpers `_make_repo`, `_make_client`, `_make_pr` in each test file for consistent setup
- `TrackingCommandRunner` records commands for assertion; use `raise_called_process_error_for` to simulate failures
- AboveResult/BelowResult are simple dataclasses; making fields optional requires updating type checker assertions in tests
- Pre-commit hook runs lint, typecheck, and tests automatically
