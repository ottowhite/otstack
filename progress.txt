## Codebase Patterns
- `PyGitHubRepository` uses GitPython's `self._git_repo.heads` to get branches (not `.references` which includes tags/stash)
- Test helpers: `_make_repo()` for MockRepository, `_make_pygithub_repo()` for PyGitHubRepository with real git repos
- Line length limit is 88 characters (ruff enforced)
- Pre-commit hooks run lint, typecheck, and tests automatically
- Mock classes live in `test/otstack/helpers/` (MockBranch, MockRepository, MockPullRequest, etc.)
- `TrackingCommandRunner` in test helpers tracks commands for verification
- GitPython's `repo.remote().refs` gives remote refs; use `ref.remote_head` to get branch name (excludes "HEAD" manually)
- `_make_repo()` in test_below.py and test_above.py accepts `remote_branches` parameter for MockRepository
- MockRepository has `_remote_branches: Sequence[str]` field for remote branch testing
- Non-dry-run `below()`/`above()` tests need `working_dir` in MockRepository (for git fetch step)
- `SimpleBranch` can represent remote refs like `origin/main` for `create_branch`
